# 3 分钟演示脚本（可压缩到 90 秒）

> 原则：演示者不解释技术，只让两个人把事说清楚；失败分支必须提前彩排。
> **当前仓库默认是 mock 模式**（没有讯飞/CosyVoice 凭据），所以有两套脚本：
> A 为接入真实供应商后的目标脚本，B 为当前环境的诚实演示脚本。不要用 B 冒充 A。
>
> 没有微信或小程序未发布时，可以改用后端自带的网页试用页 `GET /demo`（见 README 第 3 节），
> 用手机浏览器录音，操作与脚本一致；mock 模式同样会显示“演示模式”。

## 0. 演示前 5 分钟检查

```bash
# 1) 后端在跑，且 health 状态已知
curl -s http://127.0.0.1:8000/api/v1/health | python -m json.tool

# 2) 常用句和音频可用
curl -s "http://127.0.0.1:8000/api/v1/phrases?scenario=medical" | python -m json.tool | head -40

# 3) 双向链路冒烟（不需要麦克风）
python scripts/smoke_test.py
```

- 如果 `health.dependencies.asr.mode != "live"`，**只能走脚本 B**。
- 打开微信开发者工具 → 导入 `miniprogram/` → 详情 → 本地设置 → 勾选“不校验合法域名”。
- 手机真机演示前，把 `miniprogram/config.js` 的 `API_BASE` 改成可访问的 https 地址（见 README）。
- 准备 1 个备用热点；常用句页和本地音频不依赖网络。

## 1. 脚本 A：真实链路（目标形态，90 秒）

| 时间 | 动作 | 台词 |
|---|---|---|
| 0:00 | 打开小程序首屏 | “这是小甘，只做一件事：兰州话和普通话，两个人当面把事说清楚。” |
| 0:10 | 选“就医”，评委 A 按住说一句兰州话 | “您按住说一句，松开就行。” |
| 0:20 | 屏幕出现原话 + 普通话译文，自动播放 | “他说的原话、普通话译文都在这；先看文字，再听声音。” |
| 0:30 | 切到“说普通话”，评委 B 输入一句普通话 | “反过来，不会说兰州话的人也能把话递过去。” |
| 0:45 | 出现兰州话文本 + 回译，播放兰州话 | “还有回译，方便对方确认没听错。” |
| 1:00 | 打开常用句 | “就医、出行、买卖三个场景，断网也能用。” |
| 1:15 | 关掉 TTS 或断网，演示文字卡 + 缓存语音包 | “合成失败就退回文字和语音包，不会卡在加载里。” |
| 1:30 | 说明限制 | “目前只覆盖兰州话，其他甘肃片区会在后续版本加入。” |

## 2. 脚本 B：当前 mock 环境（诚实演示，同样 90 秒）

前提：`/api/v1/health` 显示 `asr/llm/tts` 为 `mock`。此时**不要让评委自由说话**——内置演示转写不会识别他们的内容。

| 时间 | 动作 | 台词 |
|---|---|---|
| 0:00 | 打开首屏，指一下黄色横幅 | “这是原型。识别和方言合成还没接真实服务，横幅写得很清楚；今天演示的是完整交互和失败降级。” |
| 0:10 | 切到“说普通话”，输入“医生，我有点头晕。” | “先看反向：普通话进来，出兰州话文本和回译。” |
| 0:25 | 点播放 / 自动播放 | “语音来自预设包，不是现场合成；我方标注了‘示意音频’。” |
| 0:40 | 打开常用句 → 就医 | “三个场景加日常，27 句，全部在包里，断网可播。” |
| 0:55 | 点“给对方看”全屏 | “现场把手机递过去，字够大，两句话都在。” |
| 1:10 | 回首页，按住说一句（任意），展示降级 | “就算识别没接，录音、状态机、错误分支都是真的；这里会明确提示‘演示模式’。” |
| 1:25 | 说明限制 | “只覆盖兰州话；文本与方言音频待母语者校对，验收数据还没跑。” |

> 如果评委要求“说一句试试”：可以试，但必须先说“现在返回的是内置演示句，不是您的原话”，并展示 `mock_asr` 提示。不要假装识别成功。

## 3. 必须提前彩排的失败分支

| 分支 | 触发方式 | 预期表现 |
|---|---|---|
| 麦克风拒绝 | 开发者工具清缓存后拒绝授权 | 提示“需要麦克风”，可打开设置，常用句仍可进入 |
| 录音太短 | 快速点一下 | “太短了，按住多说一会儿” |
| 识别为空 | `X-Mock-Behavior: asr_empty`（或真实空音频） | “没听清”，可重说/改文字 |
| 低置信度 | `X-Mock-Behavior: asr_low` | 不自动播放，进入改字，黄色提示 |
| 网络失败 | 关掉后端 | “网络不稳，先看文字”，保留录音可重试上传 |
| TTS 失败 | `X-Mock-Behavior: tts_error` | 文字保留，提示“方言语音暂时没生成” |
| 切后台/来电 | 录音中下拉通知栏/来电 | 停止录音和播放，回来自动 idle，提示重说 |
| 重复点击 | 连续按按钮 | 按钮禁用，只有一个请求 |

## 4. 不要说的话

- “支持甘肃话/全甘肃方言” → 只能说“兰州话（试运行）”。
- “准确率 95%”“完美翻译” → 评测集尚未采集，没有任何准确率数字。
- “实时同传” → P0 是按住说一句的半双工。
- “AI 克隆了兰州话母语者音色” → 当前方言音频是占位合成，未做声音克隆。

## 5. 演示后

- 设置页展示隐私说明与“删除我的本次记录”。
- 如果被问“下一步”：母语者校对 27 条预设句 → 采集 30 句评测集 → 跑通探针 A/B → 再把 mock 换 live。
