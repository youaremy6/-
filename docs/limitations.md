# 能力边界与已知风险

> 这份文件写给评审、后续开发者和演示者。**任何对外材料都不应越过这里的边界。**

## 1. 范围边界

| 项目 | P0 事实 |
|---|---|
| 方言范围 | 只做**兰州话（试运行）**，不是“甘肃话”。甘肃内部还有中原官话、兰银官话其他片区，口音差异明显。 |
| 交互 | 半双工单句：按住说一句 → 松开 → 文字 + 语音。不做实时双讲/同传。 |
| 场景 | 就医、出行、买卖三个场景的常用句；不是通用翻译器。 |
| 用户 | 不做注册、社交、排行榜、运营后台。 |
| 医疗/法律 | 只做语言转写与表达转换，不做诊断、法律或金融建议。 |

## 2. 当前实现的真实状态

### 2.1 ASR 优先本地真实识别，不可用时退回 mock

- 配有 `faster-whisper` 且本地有模型时，ASR 是 `WhisperASR`：真实转写，带兰州话常用词 prompt，`/health` 显示 `asr=whisper/local`。
- 模型/依赖不可用时，退回 `MockASR`：跳过开头静音后按有声段哈希从 27 条预设句里选一句，**不识别内容**；全静音返回“没听清”。
- 没有配置 LLM 时，`MockLLM` 用预设句对照表 + 19 条保守词表；不确定就不改，降低置信度。
- 没有配置 CosyVoice3 时，`MockTTS` 只返回预设包音频；包外文本返回文字 + `tts_error`。
- UI 只在仍有 mock 组件时显示黄色“演示模式”横幅；结果可能带 `demo` 提示；`/health` 明确标注每个组件的模式。

### 2.2 预设句与音频

- 27 条文本 **全部是 draft**，未经兰州话母语者校对。
- 兰州话音频 **20 条是 placeholder**（普通话音色朗读方言文本），另有 **7 条真人录音**（`help_01~07`：组撒、没麻达、攒劲、干散、瓜怂、日厌、坏怂）。
- 普通话音频默认是本地 TTS 示例，不是真人录音。
- 发布前必须：母语者逐条校对文本 → 重录方言音频 → 把 `reviewStatus` 改为 `verified`。
- 真人录音的替换路径已经打通：把文件放到 `assets/phrases/recordings/lanzhou/<phrase_id>.wav|.mp3`，
  运行 `python scripts/build_phrases.py`，`kind` 会变为 `recorded`，UI 的占位标记自动消失；
  构建会保留已有音频，不会每次重新合成。详见 `assets/phrases/recordings/README.md`。
- 音频目前随小程序包发布（离线可用），所以替换后需要重新发版。若要求“后台上传立即生效”，
  需要改为服务端下发常用句音频 URL 并在启动时拉取/缓存，这一模式尚未接。

### 2.3 未经真机验证

- 本仓库在开发机完成：71 项后端测试、真实 HTTP 冒烟、小程序静态检查（3 页面/handler/状态机/54 个音频），以及用 `wx` API stub 驱动的**页面级仿真**（`scripts/simulate_miniprogram.mjs`，跑通录音→上传→结果→改字→反向输入→常用句→设置删除）和 headless Chrome + fake mic 的 **H5 录音链路验证**（`scripts/verify_h5.py`）。
- **没有在微信开发者工具和真机上实际点过**。页面仿真不能替代真实录音（PCM 是否有 WAV 头）、`audioMode` 兼容性、真机播放、来电打断等，必须以真机结果为准。
- 真机还需要：合法 https 域名或云托管、备案；本地 `http://127.0.0.1:8000` 在手机上不可达。
- 本地 Whisper small 是通用中文模型，不是甘肃话专用；短词/生僻词会错。实测 `没麻达`、`干散`、`组撒` 可识别，`攒劲`、`日厌`、`坏怂` 仍可能错。要求稳定方言准确率时用讯飞甘肃话 ASR。

### 2.4 评测未执行

- `eval/lanzhou/` 有 30 条 metadata 与 CER 工具，但**没有真实录音**，`results.csv` 为空。
- 因此 CER、意思保留、TTS 可懂度/像不像**全部未知**。不得对外宣称准确率。
- 通过标准见 `docs/spikes.md`；未通过就必须维持降级。

## 3. 技术风险

| 风险 | 说明 | 缓解 |
|---|---|---|
| 讯飞方言参数不确定 | `XF_ACCENT_GANSU` 必须控制台开通后读取，代码未硬编码 | 缺失即禁用 live；探针脚本先验证 |
| PCM 容器差异 | 微信不同基础库可能给裸 PCM 或 WAV | 服务端同时接受 WAV 与裸 PCM，其他一律 415 |
| CosyVoice 音色来源 | 参考音频必须书面同意，且不能是公众人物/未成年人 | 未配置时只用预设包；文档写死边界 |
| LLM 编造方言词 | 模型可能生造词 | prompt 禁用词表外造词；低置信度提示；draft 标记 |
| LLM 改写数字/金额 | 就医与买卖场景不可接受 | prompt 强制保留；评测集覆盖；不做静默换算 |
| 单进程内存状态 | 幂等缓存、锁、记录都在进程内，多 worker 不一致 | 生产换 Redis/DB；P0 单进程演示 |
| 本地签名密钥 | 未配置时使用开发固定派生值 | `.env` 设置 `MEDIA_SIGNING_SECRET` |
| 无鉴权/限流 | 公网暴露会被刷 | 前置网关鉴权、限流、配额 |
| 音频 TTL | 链接 1 小时过期，长演示可能失效 | 过期后重新生成；离线用预设包 |
| 音频 TTL | 链接 1 小时过期，长演示可能失效 | 过期后重新生成；离线用预设包 |
| H5 麦克风 | 浏览器只在 HTTPS/localhost 下允许录音；微信内置浏览器可能拒绝 | 用 cloudflared/ngrok 或正式 https；失败时用文字与常用句 |
| 播放语速 | `InnerAudioContext.playbackRate` 部分基础库不支持 | 已 try/catch，按原速播放 |

## 4. 隐私与合规边界

- 原始录音不落库：只在请求内存中处理，临时文件用后即删（`AUDIO_RETENTION_HOURS=0`）。
- 日志只含 `request_id / method / path / status / duration / error code`，不含原文、译文、音频。
- 生成语音保留 60 分钟用于播放，可在设置页“删除我的本次记录”立即删除。
- 声音参考样本必须绑定同意记录，支持撤回与删除；不得克隆公众人物、未成年人或未授权第三方声音。
- 不把用户音频默认用于训练。
- 结果卡标注“AI 生成语音”。

## 5. 明确不做（P0）

- 不做全甘肃方言、多片区音色市场。
- 不做实时双讲/同传/离线大模型。
- 不做用户注册、社交、排行榜、复杂运营后台。
- 不做未经同意的声音克隆、公众人物音色。
- 不做医疗诊断、法律建议、金融建议。
- 不把 API Key 放进小程序。
- 不用“高准确率”“完美翻译”等无法验证的承诺。
